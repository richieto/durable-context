# Backfill Evidence Rules

- Cite paths, commits, tests, commands, or diffs for observed claims.
- Attribute human-confirmed intent with the confirmation date.
- Keep inferred claims visibly provisional until the human confirms or rejects
  them.
- Do not infer why code changed merely from what changed.
- Record unavailable session history as unknown; user-provided summaries are
  evidence only after attribution.
- Treat branch names and external work-item identifiers as provenance, never as
  the initiative identity.
